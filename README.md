# SSE-SocialShareExtension（一鍵分享文章 Chrome 擴充功能）

在任何文章頁面點一下，加上你的評論，分享到 **Threads、Facebook、Instagram、X**。

## 功能

- 自動抓取當前頁面的標題與網址（優先使用 `og:title` 與 canonical 網址）。
- 先選取一段文字再開啟，會自動放進評論框當引言。
- 評論框可自由編輯，可選擇是否附上標題。
- 即時顯示 X 的字數（上限 280）。
- 記住你上次勾選的平台。

## 各平台行為

| 平台 | 行為 |
|---|---|
| Threads | 開啟發文視窗，評論、標題、連結已預填，可再修改後發佈。 |
| X | 開啟發文視窗，內容已預填，可再修改後發佈。 |
| Facebook | 開啟分享視窗並帶入連結。Facebook 不接受預填文字，評論會先複製到剪貼簿，請在視窗內貼上。 |
| Instagram | 網頁版沒有分享連結功能，只會開啟 instagram.com，並把評論與連結複製到剪貼簿，請自行貼上。 |

所有平台都由你**自己確認後按發佈**，擴充功能不會代替你送出貼文。

## 安裝（手動安裝，未上架 Chrome 線上應用程式商店）

本擴充功能**沒有上架** Chrome 線上應用程式商店，需要用「載入未封裝項目」的方式自行安裝，約一分鐘即可完成。原始碼全部公開，只有幾個小檔案，安裝前可以自行檢查。

### 步驟

**1. 下載檔案**

到本倉庫首頁，按綠色的 **Code** 按鈕，選 **Download ZIP**，下載後**解壓縮**到一個你不會刪除的位置（例如 `文件\SSE-SocialShareExtension`）。

> 已安裝 Git 的話，也可以用 `git clone https://github.com/Ascentek-info/SSE-SocialShareExtension.git`。

**2. 開啟擴充功能頁面**

在 Chrome 網址列輸入 `chrome://extensions` 後按 Enter。

**3. 開啟開發人員模式**

打開頁面**右上角**的「開發人員模式」開關。

**4. 載入擴充功能**

按左上角的**載入未封裝項目**，選擇剛才解壓縮出來的資料夾，也就是裡面直接看得到 `manifest.json` 的那一層，再按「選擇資料夾」。

**5. 釘選到工具列**

點網址列右邊的拼圖圖示，找到「SSE-SocialShareExtension」，按旁邊的圖釘，之後就能在工具列一鍵使用。

### 使用

打開任何一篇文章，點工具列的圖示，寫評論、勾選要分享的平台，按**分享**即可。

### 注意事項

- **不要刪除或搬動解壓縮的資料夾**：Chrome 是直接讀取該資料夾，資料夾不見，擴充功能就會失效。
- **Chrome 可能提醒「停用開發人員模式的擴充功能」**：重新啟動 Chrome 時偶爾會跳出，按「取消」或關閉視窗，保留擴充功能即可。
- **更新版本**：重新下載 ZIP，覆蓋原本的資料夾，再到 `chrome://extensions` 按擴充功能卡片上的**重新整理**圖示。
- **移除**：在 `chrome://extensions` 按「移除」即可，不會留下任何資料。
- **Edge、Brave 等 Chromium 瀏覽器**：做法相同，Edge 的網址是 `edge://extensions`，Brave 是 `brave://extensions`。
- **Firefox、Safari 不支援**，本擴充功能是 Chrome Manifest V3 格式。

## 隱私

- **不收集、不傳送任何資料**到我們或第三方伺服器，程式內沒有任何網路請求，而且擴充功能的內容安全政策（CSP）設為 `connect-src 'none'`，瀏覽器會直接擋掉任何連線。
- **分享前自動清理網址**：移除追蹤參數（`utm_*`、`fbclid` 等）、疑似登入憑證的參數（`token`、`session` 等）與網址中的帳號密碼；本機與內網網址（`localhost`、`192.168.x.x` 等）會拒絕分享。
- 更多細節見 [SECURITY.md](SECURITY.md)。
- 唯一儲存的東西是你上次勾選的平台，存在你自己瀏覽器的 `chrome.storage.local`。
- 你的評論與連結，只會在你按下分享時，送到你自己選擇的平台。

### 權限說明

| 權限 | 用途 |
|---|---|
| `activeTab` | 只在你點擊圖示時，讀取當前分頁。 |
| `scripting` | 讀取頁面標題、canonical 網址與你選取的文字。 |
| `storage` | 記住上次勾選的平台。 |
| `clipboardWrite` | Facebook / Instagram 無法預填文字，改為複製到剪貼簿。 |

## 已知限制

- 各平台的分享網址可能隨改版而變動，若某平台沒有帶入內容，歡迎開 Issue 回報。
- 在 `chrome://` 等受限頁面無法讀取選取文字，會改用分頁標題與網址。
