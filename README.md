# 一鍵分享文章（Chrome 擴充功能）

在任何文章頁面點一下，加上你的評論，分享到 **Threads、Facebook、Instagram、X**。

## 功能

- 自動抓取當前頁面的標題與網址（優先使用 `og:title` 與 canonical 網址）。
- 先選取一段文字再開啟，會自動放進評論框當引言。
- 評論框可自由編輯，可選擇是否附上標題。
- 即時顯示 X 的字數（上限 280）。
- 記住你上次勾選的平台。

## 各平台行為

| 平台 | 行為 |
|---|---|
| Threads | 開啟發文視窗，評論、標題、連結已預填，可再修改後發佈。 |
| X | 開啟發文視窗，內容已預填，可再修改後發佈。 |
| Facebook | 開啟分享視窗並帶入連結。Facebook 不接受預填文字，評論會先複製到剪貼簿，請在視窗內貼上。 |
| Instagram | 網頁版沒有分享連結功能，只會開啟 instagram.com，並把評論與連結複製到剪貼簿，請自行貼上。 |

所有平台都由你**自己確認後按發佈**，擴充功能不會代替你送出貼文。

## 安裝

1. 下載或 clone 此倉庫。
2. 在 Chrome 開啟 `chrome://extensions`。
3. 開啟右上角的**開發人員模式**。
4. 按**載入未封裝項目**，選擇本專案資料夾。
5. 把擴充功能釘選到工具列。

Edge、Brave 等 Chromium 瀏覽器用同樣方式載入（Edge 網址為 `edge://extensions`）。

## 隱私

- **不收集、不傳送任何資料**到我們或第三方伺服器，程式內沒有任何網路請求。
- 唯一儲存的東西是你上次勾選的平台，存在你自己瀏覽器的 `chrome.storage.local`。
- 你的評論與連結，只會在你按下分享時，送到你自己選擇的平台。

### 權限說明

| 權限 | 用途 |
|---|---|
| `activeTab` | 只在你點擊圖示時，讀取當前分頁。 |
| `scripting` | 讀取頁面標題、canonical 網址與你選取的文字。 |
| `storage` | 記住上次勾選的平台。 |
| `clipboardWrite` | Facebook / Instagram 無法預填文字，改為複製到剪貼簿。 |

## 已知限制

- 各平台的分享網址可能隨改版而變動，若某平台沒有帶入內容，歡迎開 Issue 回報。
- 在 `chrome://` 等受限頁面無法讀取選取文字，會改用分頁標題與網址。
